# 🎄 Christmas 2D Web Game 🎮

A simple and fun 2D web-based game developed using **HTML, CSS, and JavaScript**, themed around Christmas.  
This project was created as a learning experience to practice game logic, animations, collision detection, and DOM manipulation.

# ✨ Features
- 🎅 Animated Santa character (idle, walk, jump, death)
- 📦 Moving enemies with collision detection
- 🎁 Victory condition with animated gift
- 🧮 Live score system
- 🎮 Keyboard controls

# 🎮 How to Play
- **Press ENTER** → Start the game  
- **Press SPACE** → Jump  
- Avoid enemies and survive until you reach the victory condition!

# 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript**

# 🎯 Learning Outcomes
- Improved understanding of JavaScript animations
- Better grasp of game loops and timing (`setInterval`)
- Collision detection logic
- DOM-based game development
- Structuring a complete mini game project
